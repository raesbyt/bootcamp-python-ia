# 💻 Bootcamp Santander 2026: Dados com Python🐍 e IA🤖

> ⚠️ **Nota:** Este é um repositório **pessoal de estudos e anotações** criado para acompanhar... leia em ``README``.


O **Santander Bootcamp 2026** oferece uma formação intensiva de **Dados com Python e IA** , desenvolvida para capacitar profissionais na análise, tratamento e automação de dados, combinando a flexibilidade da linguagem `Python` com o ecossistema moderno de `Inteligência Artificial`. 
<br>O programa abrange desde os fundamentos de sintaxe, estruturas de dados, POO e bancos de dados até o uso de bibliotecas de análise (`pandas`, `numpy`), visualização (`matplotlib`, `seaborn`), **Machine Learning**, **Engenharia de Prompts** e a orquestração de **Agentes Autônomos de IA**.

Aprofundamento nas coleções nativas da linguagem (`list`, `tuple`, `set`, `dict`) e na criação de funções modulares e reutilizáveis:

- [ ] Aplicando Encapsulamento em Python
- [ ] Conhecendo Polimorfismo em Python
- [ ] Interfaces e Classes Abstratas com Python
